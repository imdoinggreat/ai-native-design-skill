# Motion as attention design

Read this when the task involves animation, camera movement, transitions, or animated explanations.

## Plan beats before effects

For each beat, specify:

| Field | Question |
|---|---|
| Time range | When does the beat start, settle, and end? |
| Focal point | What single thing should the viewer notice? |
| Message or action | What must they understand or do? |
| Reading hold | How long does the content stay stable? |
| Transition purpose | Why does movement help comprehension? |
| Continuity | What object, position, or relationship connects the states? |
| Reduced-motion version | How is the meaning conveyed without movement? |

Estimate timing from the actual text, audience, and playback context. Test playback at normal speed. A universal words-per-second value is insufficient for labels, charts, unfamiliar terms, and translated copy.

Sequence competing movements so attention can transfer. Concurrent movement can work when elements form one perceptual unit; specify the shared focus instead of banning all simultaneous animation.

Preserve identity and spatial relationships during transitions. A camera flourish should not hide the destination, disorient the viewer, or become the only route to content. For interactive scenes, retain keyboard access and direct navigation; for passive video, keep text legible and make the message understandable without sound.

## Ordinary feature example: export CSV

Assumption: the product already supports exporting the visible filtered table. Confirm that behavior before depicting it. All records below are illustrative.

| Time | Focus and message | Movement, hold, continuity |
|---|---|---|
| 0–4s | Filtered table; “Take this view with you.” | Brief selection emphasis, then stable reading hold. |
| 4–8s | Export control; “Export CSV.” | Move attention to the real control. Keep the table still. |
| 8–13s | Downloaded file; “Your filtered rows, in a file.” | Carry the table title to the file label, then hold. |
| 13–17s | Same rows opened in a spreadsheet | Match column names and values; settle before reading. |
| 17–20s | Final action; “Export your view.” | Return to the product control, then hold the end frame. |

Check that the holds are sufficient in playback; shorten copy before accelerating the viewer. Represent empty, failed, or large exports accurately if those states matter to the request. Do not imply instant performance or time savings without evidence.

A reduced-motion version uses stable frames and simple cuts with the same message sequence. Evaluate whether a viewer can explain what is exported and where it goes, separately from whether the piece looks impressive.
